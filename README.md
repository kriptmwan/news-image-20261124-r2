## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

`main.py` (Python standard library only) copies `entry.png` to `/output/entry.png`. `render.py` draws `entry.png` from scratch with Pillow at build time; it is not run by the entry.
